# SmartNote

AI 문제 풀이가 내장된 학습용 필기 노트 웹앱입니다.

## 핵심 기능

### 1. AI 문제 풀이 · 채점
- 툴바의 **AI 풀이**(단축키 `A`)를 고르고 문제를 펜으로 둘러싸면, 그 영역을 이미지로 만들어 AI(Claude)에 보냅니다. 답은 영역 옆 카드에 실시간으로 적힙니다.
- 영역 안에 **내 풀이와 답**이 있으면 AI가 채점해서 `정답` / `오답` / `부분 정답` 배지를 붙이고, 틀린 곳과 고치는 방법을 알려 줍니다.
- 올가미로 선택한 내용도 선택 도구 모음의 **풀이** 버튼으로 보낼 수 있습니다.
- 카드에서 다시 풀기, 복사, 접기, 끌어서 옮기기를 할 수 있고, 카드에 마우스를 올리면 처음 둘러싼 영역이 표시됩니다. 수식은 LaTeX(KaTeX)로 렌더링됩니다.

### 2. 손글씨 → 텍스트 변환
- **텍스트 변환**(단축키 `C`)을 고르고 손글씨를 둘러싸면, 그 안의 펜 획을 AI가 인식해 컴퓨터 글자로 바꿉니다. 한글, 영어, 수식(x², √, ≤ 같은 유니코드 기호)을 지원합니다.
- 결과는 바로 적용되지 않고 **미리보기 창**에 뜹니다. 잘못 인식된 글자를 고친 뒤 고를 수 있습니다.
  - **텍스트로 바꾸기**(`Ctrl/⌘+Enter`): 손글씨를 지우고 같은 자리에 텍스트를 넣습니다.
  - **아래에 추가**: 손글씨는 그대로 두고 아래에 텍스트를 덧붙입니다.
- 변환된 텍스트는 바로 선택된 상태가 됩니다. 수정하는 방법은 두 가지입니다.
  - 선택 도구 모음의 **수정** 버튼을 누릅니다. 같은 곳의 A−/A+ 버튼으로 크기를, **기본 크기** 버튼으로 기본값을 맞출 수 있습니다.
  - 텍스트를 **더블클릭**합니다. 펜·형광펜·지우개를 제외한 모든 도구에서 됩니다.
- 실행 취소 한 번이면 손글씨가 되돌아옵니다.
- 올가미로 선택한 획은 선택 도구 모음의 **텍스트로** 버튼으로도 변환할 수 있습니다.

### 글자 크기 통일
- **기본 글자 크기**는 설정, 텍스트·변환 도구의 툴바, 변환 미리보기 창에서 정할 수 있습니다. 이 크기는 아래 세 경우에 항상 적용되어 노트의 글자 크기가 통일됩니다.
  - 복사한 문제 텍스트를 붙여넣을 때 (`Ctrl/⌘+V`)
  - 손글씨를 텍스트로 변환할 때
  - 새 텍스트 상자를 만들 때
- 붙여넣은 텍스트는 마우스 위치 근처의 빈 자리에 놓입니다.
- 손글씨 크기에 맞추고 싶으면 설정의 **변환할 때 손글씨 크기 따라가기**를 켜면 됩니다.

### 3. 표
- **표**(`B`): 최대 8×8 크기를 고른 뒤 페이지를 클릭하면 표가 생깁니다.
- 행/열 경계선을 **드래그**하면 셀 너비와 높이가 바뀝니다.
- **지우개**로 내부 선을 문지르면 그 선이 지워지면서 **셀이 병합**됩니다.
- 표 도구에서는 지운 선이 점선으로 보이고, 클릭하면 다시 그려집니다. 셀을 더블클릭하면 글자를 입력할 수 있습니다.
- 표를 선택하면 행/열 추가·삭제, 병합 모두 해제, 셀 크기 균등화 버튼이 나옵니다.
- **꼭짓점**(네 귀퉁이 핸들)을 드래그하면 가로세로 비율을 유지한 채 표 전체 크기가 바뀝니다. 글자 크기도 같은 비율로 바뀌고, 반대쪽 꼭짓점은 제자리에 있습니다.
- **테두리나 꼭짓점을 클릭**하면 **표 삭제** 탭이 뜹니다. 삭제 후 토스트의 "되돌리기"나 `Ctrl+Z`로 되돌릴 수 있습니다.
- 위·왼쪽 테두리를 드래그하면 표가 통째로 이동합니다.
- 이 핸들들은 올가미(V)·표(B) 도구에서 동작합니다. 펜으로 쓸 때는 표 가장자리에서도 그대로 필기됩니다.

### 4. 강의자료 참조
- 상단 **강의자료**에서 PDF, TXT/MD, 이미지를 노트별로 올립니다. 파일은 Anthropic Files API로 업로드됩니다.
- AI가 풀이할 때 자료의 정의, 표기법, 공식을 따르고, 참고한 자료와 페이지를 밝힙니다.
- 자료마다 참조 여부를 켜고 끌 수 있습니다. 자료 부분에는 프롬프트 캐시가 적용되어, 같은 자료로 반복해서 풀면 더 빠르고 저렴합니다.

### 노트앱 기본 기능
- **필기**: 필압 펜, 형광펜(`Shift`로 직선), 획 지우개, 올가미 선택(이동·크기 조절·색 변경·복제·삭제), 텍스트 상자, 이미지 붙여넣기와 끌어놓기
- **화면 조작**: 휠·스페이스·두 손가락으로 이동, `Ctrl`+휠·핀치로 확대, 폭 맞춤
- **S펜·손바닥 인식 방지 (펜 전용 모드, 기본 켜짐)**
  - 글씨는 펜으로만 써집니다. 손가락은 한 손가락이면 화면 이동, 두 손가락이면 확대만 합니다.
  - 펜으로 쓰는 중이거나, 펜이 화면 위에 떠 있거나, 펜을 뗀 지 0.5초가 안 됐을 때 닿는 터치는 무시합니다. 손바닥처럼 넓은 터치도 무시합니다.
  - 그리던 획은 처음 닿은 포인터만 따라가므로, 손바닥이 닿았다 떨어져도 획이 끊기지 않습니다.
  - **S펜 측면 버튼을 누르는 동안 지우개**가 됩니다.
    - 쓰는 도중에 버튼을 누르면 바로 지우개로 바뀌고, 떼면 그 자리부터 다시 펜으로 씁니다.
    - 버튼을 누른 채 펜을 화면 위에 띄우면 지우개 커서가 보이고, 툴바의 지우개 버튼에 표시가 생깁니다.
    - 쓰던 중 버튼을 눌렀을 때 펜 끝 아래에 있는 방금 쓴 획은 지워지지 않게 보호합니다.
  - 툴바의 **펜 전용** 버튼으로 끄면 손가락으로도 필기할 수 있습니다.
- **정리**: 노트(색상 표지)와 페이지 썸네일, 페이지 드래그 재정렬·복제·삭제(되돌리기 가능), 배경(무지/줄/모눈/도트), 필기 텍스트 검색
- **편의**: 자동 저장(IndexedDB, 오프라인 동작), 실행 취소/다시 실행, PNG·PDF 내보내기, 다크 모드, 단축키(설정 화면에서 전체 목록 확인)

## 실행

```bash
npm install
cp .env.example .env    # ANTHROPIC_API_KEY 입력 (또는 앱 설정 화면에서 개인 키 입력)
npm run dev             # http://localhost:5173
```

배포용으로 실행하려면:

```bash
npm run build && npm start   # http://localhost:8787 에서 서버가 빌드된 앱도 함께 제공
```

### claude.ai 아티팩트로 실행 (서버·API 키 없이)

```bash
npm run build:artifact   # dist/artifact.html + dist/assets/* 생성
```

같은 빌드가 실행 환경을 알아서 감지하고, 아티팩트로 열리면 아래처럼 동작합니다.
- AI 풀이와 텍스트 변환은 `/api` 서버 대신 아티팩트의 `sample` 기능을 씁니다. 사용량은 보는 사람의 claude.ai 계정에서 차감되고, 처음 사용할 때 허용 여부를 묻습니다.
- 강의자료는 브라우저에서 바로 읽습니다. PDF는 pdf.js로 쪽 번호와 함께 글자를 추출하고, 텍스트와 이미지는 그대로 씁니다. 스캔본 PDF는 글자를 뽑을 수 없으니 쪽을 이미지로 올려야 합니다.
- PNG/PDF 내보내기는 `downloads` 기능으로 저장 확인 창을 거칩니다.
- 노트는 그 브라우저의 IndexedDB에만 저장됩니다.

## 구조

| 경로 | 역할 |
|---|---|
| `server/index.ts` | Express 서버. `/api/solve`(SSE 스트리밍 풀이), `/api/transcribe`(손글씨 인식), `/api/materials`(Files API 업로드/삭제) |
| `shared/prompts.ts` | 풀이·손글씨 인식 프롬프트 (서버와 아티팩트 모드가 함께 사용) |
| `src/runtime.ts`, `src/materials.ts` | 아티팩트 모드 감지, `sample`/`downloads` 연결, 브라우저 강의자료 추출 |
| `src/handwriting.ts`, `src/components/ConvertPanel.tsx` | 손글씨 → 텍스트 변환 (`/api/transcribe`) 과 미리보기 |
| `src/components/Canvas.tsx` | 캔버스: 그리기, 지우개(표 선 병합 포함), 올가미, AI 경계, 확대/이동 |
| `src/components/TableView.tsx` | 표 렌더링, 경계 드래그 크기 조절, 셀 편집, 선 복원 |
| `src/components/AnswerCard.tsx` | AI 답안 카드 (마크다운 + KaTeX, 채점 배지) |
| `src/render.ts` | 영역 래스터화(AI 입력), 썸네일, PNG/PDF 내보내기 |
| `src/store.ts` | zustand 상태, 실행 취소 기록, 자동 저장 |

- 모델: `claude-opus-5-5`. 정확도(effort)는 설정에서 빠름 / 균형 / 정확 / 최고 정확도 중에서 고릅니다.
- 거절 응답에 대비해 서버 측 fallback이 켜져 있습니다.
- API 키는 서버에만 둡니다. 설정 화면에 입력한 개인 키는 브라우저에 저장되고 요청 헤더로 서버를 거쳐 전달됩니다.
